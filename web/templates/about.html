Because the systems differ, the same word can mean different things. For example, an additive missing from the EU list may not be used at all in the EU, but a substance missing from the FDA inventory may still be used legally in the US.

How additives are matched across sources

Each source names additives differently. The EU and UK use E-numbers, the FDA uses chemical names and CAS numbers, and Health Canada uses names only. Records are joined in this order:

  1. E-number (EU and UK lists).
  2. CAS registry number (FDA inventory, via Wikidata's E-number–CAS links).
  3. Exact name after normalisation (upper/lower case, punctuation, "FD&C" spellings), using official names and Wikidata English names.
  4. A small reviewed match table for names that cannot be matched automatically, each with the reason.

If a record cannot be matched, the site shows No data instead of guessing. On each additive page, a note under each status says how the match was made.

How the data stays current

  • Every week an automated job downloads each source again and records its size, checksum and time.
  • The new data is parsed and checked: expected fields must be present, counts must not drop sharply, and key reference additives must still parse correctly.
  • If a check fails, the site keeps showing the last data that passed, and the problem is reported automatically. Broken data is not published.
  • Status differences between the new and the previous version are recorded on the changes page.

What this site does not cover

  • Not legal advice. Statuses are simplified summaries. Conditions of use (which foods, what maximum levels, purity criteria, labelling duties) are shown only in part. Always check the official source.
  • US state laws (for example California or West Virginia dye laws) are not included: there is no structured official source for them. The US column shows federal status only.
  • GRAS substances used in the US without notification are not in the FDA inventory and cannot be shown.
  • Safety values such as the acceptable daily intake (ADI) are not shown, because the licence of the main open database of these values does not allow republishing adapted data. Links to the official assessments are given where available.
  • Flavourings, enzymes and processing aids are covered only where they appear in the additive lists used here.
  • Northern Ireland follows EU food additive rules; see the EU column.
